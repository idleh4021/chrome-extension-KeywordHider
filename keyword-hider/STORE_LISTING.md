# Keyword Hider — 스토어 등록용 문구

## 간단한 설명 

화면 공유·원격 제어·스티리밍 중 등록해둔 단어(이름, 닉네임 등)를 자동으로 가려주는 프라이버시 보호 확장 프로그램

## 상세 설명

Keyword Hider는 스트리밍을 하거나 원격 제어를 받을 때, 미리 등록해둔 단어가
화면에 그대로 노출되지 않도록 자동으로 가려주는 확장 프로그램입니다.

주요 기능:
- 등록한 키워드가 페이지 텍스트에 나타나면 자동으로 마스킹(●●●) 처리
- 마스킹된 부분을 클릭하면 잠시 원문을 확인 가능
- input / textarea 입력창에 입력한 내용도 선택적으로 마스킹 (옵션에서 켜고 끌 수 있음)
- 텍스트를 드래그하고 우클릭하면 바로 키워드로 추가
- 누적 숨김 횟수 카운터 및 초기화 기능
- 모든 데이터는 브라우저 로컬에만 저장되며, 외부로 전송되지 않음

이런 분들께 추천합니다:
- 화상 회의나 라이브 스트리밍 중 화면을 공유하는 분
- 원격 지원/원격 제어를 받을 때 개인정보(이름, 계정명 등)를 가리고 싶은 분
- 튜토리얼/데모 영상을 녹화할 때 민감한 정보를 미리 가리고 싶은 분

## 카테고리 추천

생산성(Productivity) 또는 도구(Tools)

## 권한 사용 목적 (Privacy practices 탭에 입력)

- storage: 등록한 키워드 목록과 설정값을 브라우저 로컬에 저장
- contextMenus: 드래그한 텍스트를 우클릭 메뉴로 바로 키워드에 추가
- 모든 사이트에서의 콘텐츠 스크립트 실행: 사용자가 방문하는 모든 페이지에서
  등록된 키워드를 찾아 화면에서 가리기 위해 필요. 데이터는 로컬에서만
  처리되며 외부로 전송되지 않음.

## 단일 목적(Single Purpose) 설명

이 확장 프로그램의 유일한 목적은 사용자가 지정한 단어를 웹페이지 화면에서
시각적으로 가려 프라이버시를 보호하는 것입니다.
