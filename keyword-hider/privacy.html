Keyword Hider 개인정보처리방침

최종 수정일: 2026-09-10

수집하는 정보

Keyword Hider는 어떠한 개인정보도 외부 서버로 전송하거나 수집하지 않습니다.

사용자가 등록한 키워드 목록과 누적 숨김 횟수는 오직 사용자의 브라우저 내부 저장소(chrome.storage.local)에만 저장되며, 이 데이터는 개발자를 포함한 어떤 제3자도 접근할 수 없습니다. 확장 프로그램을 삭제하면 저장된 모든 데이터도 함께 삭제됩니다.

권한 사용 목적

권한 사용 목적
storage 사용자가 등록한 키워드 목록, 누적 숨김 횟수, 옵션 설정값을 브라우저 로컬에 저장하기 위해 사용합니다.
contextMenus 사용자가 웹페이지에서 텍스트를 드래그하고 우클릭했을 때, 해당 텍스트를 키워드 목록에 바로 추가할 수 있는 메뉴를 제공하기 위해 사용합니다.
콘텐츠 스크립트
(모든 사이트)		 사용자가 등록한 키워드가 현재 보고 있는 웹페이지의 텍스트나 입력창에 포함되어 있는지 확인하고, 포함되어 있다면 화면에서 시각적으로 가리기 위해 사용합니다. 이 과정은 사용자의 브라우저 안에서만 이루어지며, 검사한 페이지 내용은 어디로도 전송되지 않습니다.

데이터 전송 여부

이 확장 프로그램은 네트워크 요청을 전혀 발생시키지 않습니다. 모든 처리(키워드 검색, 마스킹, 카운터 저장)는 사용자의 로컬 브라우저 안에서만 이루어집니다.
