# Keyword Hider

화면 공유나 원격 제어 중, 미리 등록해둔 단어(이름, 닉네임, 회사명 등)가 화면에 그대로 노출되지 않도록 자동으로 가려주는 크롬 확장 프로그램입니다.

## 주요 기능

- 등록한 키워드가 페이지 텍스트에 나타나면 `●●●` 형태로 자동 마스킹 (글자 수 유추 불가)
- 마스킹된 부분을 클릭하면 잠시 원문 확인 가능 (다시 클릭 시 재마스킹)
- `input` / `textarea` 입력창에 입력된 내용도 선택적으로 마스킹 (옵션에서 켜고 끌 수 있음)
- 마스킹된 입력창에서 Backspace/Delete 시 한 글자씩이 아닌 전체 삭제
- 페이지에서 텍스트를 드래그 후 우클릭 → 바로 키워드로 추가
- 누적 숨김 횟수 카운터 및 초기화 기능
- 동적으로 추가되는 콘텐츠(SPA, 무한 스크롤 등)도 `MutationObserver`로 실시간 감지
- 페이지 로딩 시 마스킹 전 원문이 잠깐 노출되는 것을 방지 (초기 렌더링 차단 후 마스킹 완료 시 표시)
- 모든 데이터는 브라우저 로컬(`chrome.storage.local`)에만 저장되며 외부로 전송되지 않음

## 설치 (개발자 모드)

1. 이 저장소를 클론하거나 ZIP으로 다운로드
2. Chrome 주소창에 `chrome://extensions` 입력
3. 우측 상단 **개발자 모드** 켜기
4. **압축해제된 확장 프로그램을 로드합니다** 클릭 → 이 저장소(또는 압축 해제한) 폴더 선택

## 사용법

1. 툴바 아이콘 클릭 → "단어 관리 열기"에서 가릴 단어 등록
2. 등록된 단어는 이후 방문하는 모든 페이지에서 자동으로 마스킹됨
3. 페이지에서 직접 텍스트를 드래그 → 우클릭 → "Keyword Hider에 추가"로도 등록 가능
4. 팝업에서 전체 켜기/끄기 토글 및 누적 숨김 횟수 확인 가능
5. 옵션 페이지에서 대소문자 구분, 입력창 마스킹 여부, 누적 카운터 초기화 설정 가능

## 권한 사용 목적

| 권한 | 목적 |
|---|---|
| `storage` | 키워드 목록, 옵션 설정, 누적 카운터를 로컬에 저장 |
| `contextMenus` | 드래그한 텍스트를 우클릭 메뉴로 바로 키워드에 추가 |
| 콘텐츠 스크립트 (모든 사이트) | 방문 중인 페이지에서 등록된 키워드를 찾아 화면에서 가리기 위함 (로컬 처리, 외부 전송 없음) |

## 알려진 제한 사항

- `data-original` 속성에 원본 단어가 DOM에 남아 있어 개발자 도구로 직접 검사하면 확인 가능함 (화면상 시각적 노출만 차단하는 용도)
- 정규식 기반 매칭이라 등록한 단어가 다른 단어의 일부로 포함된 경우에도 매칭됨 (예: "홍길동" 등록 시 "홍길동님"의 "홍길동" 부분도 마스킹)
- `-webkit-text-security`는 Chromium 계열 브라우저에서만 지원됨
